# 3D-Word-Cloud-Arthur
Interactive word cloud website for news articles
Includes a rotatable, 3D word cloud with customizable colors
Created with TypeScript, React, and FastAPI

To run the server and install dependences:
chmod +x start.sh
./start.sh

Libraries Used:
- fastapi
- uvicorn[standard]
- requests
- beautifulsoup4
- nltk
- python-dotenv
- pydantic
- node
- react
- react-three
- react-colorful
